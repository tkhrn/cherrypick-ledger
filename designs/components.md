# 컴포넌트

여러 화면에서 반복되는 부품의 생김새와 동작 규칙. 플랫폼마다 구현은 달라도 이 규칙은 같게 유지한다.

## 거래 줄 (TransactionRow)

```
[아이콘 원]  가게명                    금액
            보조 줄 (카테고리 · 알림 N개 · 배지)
```

- **크기:** 최소 높이 `row-height`(56), 좌우 여백 `space-lg`
- **아이콘 원:** 지름 32이고, 배경은 카테고리 `bg`, 아이콘은 카테고리 `fg` 색이다. 카테고리가 없으면 `cat-gray`이고 아이콘은 종류별로 고른다(이체 `arrows-exchange`, 해석 실패 `help`).
- **가게명:** `text-body`, 한 줄로 쓰고 넘치면 말줄임을 한다. 가게명이 없으면 "가게 이름 없음"을 `text-secondary`로 보여준다.
- **보조 줄:** `text-caption`. 카테고리 이름은 카테고리 `fg` 색으로 쓴다. "알림 N개"는 2개 이상일 때만 보여준다.
- **금액:** `text-amount`, 오른쪽 정렬, 고정폭 숫자. 취소된 건은 취소선과 `text-muted`로 표시한다.
- **구분선:** 줄 아래 `border-hairline`. 마지막 줄에는 넣지 않는다.
- **밀기 동작**
  - 오른쪽으로 밀면 `status-mine` 배경과 ✓ 아이콘이 드러난다.
  - 왼쪽으로 밀면 `status-ignored` 배경과 ⊘ 아이콘이 드러난다.
  - 넘어가는 지점은 35%이다.
- **선택 모드:** 아이콘 원 자리가 체크박스로 바뀐다.

## 상태 배지 (StatusBadge)

- **모양:** `radius-pill`, 좌우 여백 8, `text-caption`
- **색:** 상태 색 토큰의 배경과 글자 색 쌍만 쓴다.
- **문구:** 내 소비 / 모임장부 / 확인 필요 / 무시 / 자동숨김 / 승인취소됨
- **표시 위치:** 정리 탭에서는 "확인 필요"만 보여준다. 나머지 상태는 숨김 목록이나 상세 시트에서 보여준다.

## 결정 선택기 (DecisionPicker)

- **배치:** 같은 너비 버튼 3개를 가로로 놓는다. 각 버튼은 아이콘 위, 이름 아래 구조다.
- **색:** 선택되지 않은 버튼은 테두리만 있다. 선택된 버튼은 해당 상태 색 배경, 2px 테두리, 상태 글자 색이다.
- **선택 후 동작:** 내 소비를 고르면 카테고리 칩 줄이, 모임장부를 고르면 모임 칩 줄이 아래에 나타난다. 무시는 추가 입력이 없다.

## 칩 (Chip)

- **모양:** `radius-pill`, 높이 30
- **색:** 기본은 `border` 테두리, 선택되면 카테고리 칩은 카테고리 `bg`/`fg`, 모임 칩은 `status-group` 색이다.
- **추가 칩:** "+ 새 모임"은 점선 테두리와 `text-secondary`로 표시한다.

## 원본 알림 박스 (RawNotificationBox)

- **모양:** 배경 `bg-subtle`, `radius-sm`, `font-mono` 11~12
- **내용:** 한 알림당 `[앱 이름] 본문 · HH:mm`
- **표시:** 원문을 그대로 보여주고 줄바꿈을 유지한다. 해석해서 뽑은 금액이나 가게를 강조하지 않는다.
- **나누기 모드:** 줄마다 체크박스를 붙인다.

## 정리 상태 영역 (OrganizeStatus)

| 상태 | 표시 |
|---|---|
| 미처리 0건 | 숨김 |
| 대기 | ⏱ "아직 정리 안 된 알림 N건" / "다음 자동 정리 HH:00" / [지금 정리하기] |
| 실행 중 | 스피너 + "정리 중…" (버튼 없음) |
| 실패 | "정리하지 못했어요" + [다시 시도] |

배경은 `bg-subtle`, 모서리는 `radius-md`이다. 목록 맨 아래에 붙는다.

## 비율 막대 (CategoryBar)

- **모양:** 높이 8, `radius-sm`, 카테고리 `bar` 색 구간을 금액 비율대로 이어 붙인다.
- **정렬:** 큰 순서로 정렬하고, 3% 미만 구간은 "기타"로 합친다.
- **탭하면:** 카테고리별 금액 목록이 펼쳐진다. 각 항목은 색 점, 이름, 금액, 비율이다.

## 달력 (MonthCalendar)

- **배치:** 7열 격자이고, 요일 머리는 일요일부터 시작한다. 일요일은 `status-cancelled` 글자 색으로 표시한다.
- **날짜 칸:** 날짜와 그날 금액(`text-micro`)을 보여준다. 0원이면 금액을 비운다.
- **오늘:** `accent` 배경 틴트로 표시한다.
- **정리할 건이 남은 날:** 금액 아래에 `status-review` 점(지름 5)을 찍는다.
- **선택한 날:** 2px `accent` 테두리로 표시한다.
- **미래 날짜:** `text-muted`로 쓰고 탭할 수 없다.

## 하단 시트 (Sheet)

- **모양:** 상단 모서리만 `radius-lg`이고, 손잡이 막대를 붙인다.
- **크기:** 내용 높이에 맞추고, 최대 화면의 90%까지다.
- **닫기:** 아래로 밀기, 바깥 탭, 뒤로 가기로 닫는다.
- **저장:** 결정은 누르는 즉시 저장한다(낙관적 업데이트). 별도의 저장 버튼은 없다.

## 알림 바 (Snackbar)

- **위치:** 하단 탭 위에 띄우고, 4초 후 사라진다.
- **문구:** "내 소비로 옮겼어요", "무시했어요", "3건 정리했어요"처럼 결과만 짧게 쓴다.
- **동작:** 항상 [되돌리기]를 제공한다.
