# 화면

1단계 화면별 와이어프레임과 동작. 색·글꼴은 [`look-and-feel.md`](./look-and-feel.md), 부품은 [`components.md`](./components.md)를 따른다.

## 내비게이션

하단 탭 4개: **정리**, **내 소비**, **모임장부**, **설정**. 앱을 열면 정리 탭이 먼저 보인다.

상단에는 필요할 때만 **수집 이상 배너**가 붙는다. 알림 접근 권한이 꺼졌거나, 24시간 넘게 수집이 없을 때다.

## 1. 첫 설정

```
[로그인] → [알림 접근 권한] → [문자 권한 (건너뛰기 가능)] → [분석할 앱 선택] → [내 계좌 등록 (건너뛰기 가능)] → 정리 탭
```

- **알림 접근 권한**
  - 왜 필요한지 한 문장으로 설명하고, "권한 설정 열기" 버튼을 둔다.
  - 시스템 설정에서 돌아오면 권한을 다시 확인한다.
- **분석할 앱 선택**
  - 설치된 앱 목록을 보여준다. 이름에 은행·카드·페이·뱅크·증권이 들어간 앱과 알려진 금융앱 패키지는 위에 "금융앱으로 보여요" 묶음으로 둔다.
  - 문자는 목록 맨 위의 별도 항목이다.
  - 검색이 가능하고, 하나 이상 골라야 다음으로 넘어간다.
- **내 계좌 등록**
  - 은행 이름과 끝 4자리, 별칭(선택)을 입력한다. 여러 개 추가할 수 있다.
  - "내 계좌끼리 옮긴 돈은 자동으로 숨겨요"라는 설명을 붙인다.

## 2. 정리 탭

```
┌────────────────────────────────┐
│ 정리                10월 5일(일)│
│ 정리할 소비 5건 · 합계 104,700원 │
├────────────────────────────────┤
│ 오늘                            │
│ (●) 스타벅스         5,600원    │
│     카페·간식 · 알림 3개         │
│ (●) 김OO 이체       30,000원    │
│     [확인 필요]                  │
│ 어제                            │
│ (●) 무신사          49,000원    │
├────────────────────────────────┤
│ ⏱ 아직 정리 안 된 알림 3건        │
│   다음 자동 정리 15:00 [지금 정리하기]│
└────────────────────────────────┘
```

- **목록**
  - `pending` 건을 날짜 묶음(오늘, 어제, 10월 3일(금) …)으로 최신순 정렬한다.
  - 날짜 묶음 머리에는 그날 정리할 건수와 합계를 보여준다.
- **각 줄**
  - 카테고리 아이콘 원, 가게명, 보조 줄, 금액으로 구성한다.
  - 보조 줄에는 카테고리 이름과 "알림 N개"(2개 이상일 때)를 보여준다. 확인이 필요한 건은 배지를 붙인다.
- **동작**
  - 오른쪽으로 밀면 내 소비로 처리한다. 추천 카테고리가 있으면 그대로 쓰고, 없으면 상세 시트를 연다.
  - 왼쪽으로 밀면 무시한다.
  - 탭하면 상세 시트를 연다.
  - 길게 누르면 선택 모드가 된다. 상단에 "N건 선택 · 내 소비 · 무시 · 취소"가 나타난다.
- **처리 직후**
  - 화면 아래에 "내 소비로 옮겼어요 · 되돌리기" 알림 바를 4초간 띄운다.
- **하단 정리 상태 영역**
  - 미처리 원문이 0건이면 숨긴다.
  - 정리 중이면 버튼 대신 "정리 중…" 스피너를 보여준다. 끝나면 목록을 자동으로 새로 고친다.
  - 실패하면 "정리하지 못했어요. 다시 시도" 문구를 보여준다.
- **빈 상태**
  - 제목 "오늘은 다 정리했어요", 본문 "새 결제 알림이 오면 여기에 모여요."
  - 숨김 처리된 건이 있으면 "자동으로 숨긴 건 N개 보기" 링크를 둔다.

## 3. 상세 시트

```
┌────────────────────────────────┐
│ 고기굽는집               20,000원│
│ 10월 5일 19:42 · 식비 추천       │
│ ┌──────┐┌──────┐┌──────┐       │
│ │✓내 소비││📒모임장부││⊘ 무시 │       │
│ └──────┘└──────┘└──────┘       │
│ 카테고리: [식비][카페][교통]…     │  ← 내 소비 선택 시
│ 모임:    [풋살][대학 동기][+]     │  ← 모임장부 선택 시
│ 메모 ____________________       │
├────────────────────────────────┤
│ 원본 알림 2개           나누기    │
│ ┌ [신한카드] 20,000원 승인 …  ┐  │
│ └ [토스] 고기굽는집에서 …     ┘  │
│ 합칠 건 찾기                     │
└────────────────────────────────┘
```

- **세 갈래 선택:** 내 소비, 모임장부, 무시 중 하나를 고른다. 이미 결정한 건이면 현재 선택이 강조돼 있다.
- **카테고리·모임 칩:** 가로로 넘겨 본다. 모임은 시트 안에서 새로 만들 수 있다.
- **확인 필요 사유:** `needs_review`인 건은 시트 상단에 사유를 한 줄로 보여준다. 예: "같은 금액 결제가 근처에 있어 묶음이 확실하지 않아요".
- **나누기:** 원본 알림 앞에 체크박스가 나타난다. 골라서 "따로 분리"를 누르면 새 건으로 떨어져 나간다.
- **합칠 건 찾기:** 앞뒤 1시간 안에 있는 같은 금액의 `pending` 건 목록을 보여준다. 골라서 합친다.
- **취소된 건:** 상단에 "승인취소됨" 배지를 붙이고, 금액에 취소선을 긋는다.

## 4. 내 소비 탭

- **상단**
  - 월 이동(‹ 2026년 10월 ›), 월 합계(`text-amount-lg`), 카테고리 비율 막대를 보여준다.
  - 막대를 탭하면 카테고리별 금액 목록이 펼쳐진다.
- **보기 전환:** 목록과 달력을 오른쪽 위에서 전환한다. 마지막 선택을 기억한다.
- **목록 보기:** 날짜 묶음별로 `mine` 건을 보여준다. 줄을 탭하면 상세 시트가 열려 결정을 바꿀 수 있다.
- **달력 보기**
  - 7열 월 달력이다. 각 날짜 칸에는 날짜와 그날 합계(`text-micro`, 0원이면 비움)를 보여준다.
  - 오늘은 `accent` 배경, 미래 날짜는 `text-muted`로 표시한다.
  - 그날 `pending` 건이 남아 있으면 `status-review` 색의 작은 점을 찍는다.
  - 날짜를 탭하면 달력 아래에 그날 목록이 펼쳐진다. 정리할 건이 있으면 "정리하러 가기" 링크도 함께 보여준다.
- **카테고리 필터:** 비율 막대에서 카테고리를 탭하면 목록과 달력이 그 카테고리로 걸러진다.
- **합계 규칙:** 취소된 건은 합계에서 빠지고, 목록에서는 취소선으로 표시한다.

## 5. 모임장부 탭

- **상단 모임 칩:** "전체 / 풋살 / 대학 동기 / …"로 거른다.
- **월 합계:** 선택한 모임의 월 합계를 보여준다. 비율 막대는 없다.
- **보기 전환:** 내 소비 탭과 같은 목록과 달력 전환이다.
- **각 줄:** 모임 아이콘(`users`)을 쓰고, 보조 줄에 모임 이름을 보여준다.
- **빈 상태:** "모임장부가 비어 있어요" + "정리할 때 모임장부를 고르면 여기에 모여요."

## 6. 설정

| 섹션 | 항목 |
|---|---|
| 수집 | 분석할 앱 (첫 설정과 같은 화면), 문자 수집 켜기/끄기, 수집 상태(마지막 수집 시각, 업로드 대기 N건), 배터리 최적화 예외 안내 |
| 정리 | 내 계좌, 카테고리(추가·이름 변경·색 선택·순서·보관), 모임(추가·이름 변경·보관) |
| 알림 | 정리 알림 시각 (기본 21:00) |
| AI | 월 호출 한도(기본 300회), 이번 달 호출 수 막대 |
| 기록 | 숨김 처리된 건 보기(자동숨김과 무시, 되돌리기 가능) |
| 계정 | 로그아웃 |

## 7. 수집 이상 배너

- **위치와 색:** 화면 최상단에 `status-review` 색으로 띄운다.
- **문구 예시:**
  - "알림 수집이 꺼져 있어요" + [권한 켜기]
  - "하루 넘게 새 알림이 없어요. 배터리 최적화를 확인해 주세요" + [확인하기]
- **닫으면** 24시간 동안 다시 띄우지 않는다.
