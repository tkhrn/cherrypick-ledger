# 룩앤필

cherrypick-ledger의 시각 언어. 특정 플랫폼(RN, 웹, 데스크탑, 크롬 확장)에 묶이지 않는 기준이며, 각 플랫폼은 아래 토큰을 자기 형식(TS 상수, CSS 변수 등)으로 옮겨 쓴다.

## 콘셉트

**"PR을 리뷰하듯 소비를 골라 담는다."** 차분한 리뷰 도구 같은 느낌을 기본으로 하고, 색은 구분이 필요한 곳에 분명하게 쓴다.

## 브랜드

- **마크**: 두 알 체리 ([`brand/cherry-mark.svg`](./brand/cherry-mark.svg)). 왼쪽 알은 크림색 "결제 내역(줄 세 개)", 오른쪽 알은 체리 레드 "골라 담은 내 소비(체크)". 꼭지·잎은 작은 크기에서도 보이게 굵게 둔다.
- **단색 마크**: [`brand/cherry-mark-mono.svg`](./brand/cherry-mark-mono.svg). 안드로이드 테마 아이콘처럼 한 가지 색으로만 그릴 때 쓴다. 줄·체크는 뚫어서 표현한다.
- **브랜드 색**

  | 토큰 | 값 | 용도 |
  |---|---|---|
  | `brand-cherry` | #C8364B | 마크 오른쪽 알, 로그인 버튼 |
  | `brand-cherry-pressed` | #A82B3E | 브랜드 버튼 누름 |
  | `brand-leaf` | #2F5D3A / 잎 #3E7B4C | 꼭지·잎 |
  | `brand-cream` | #FBF3EC | 아이콘 배경, 스플래시·로그인 화면 배경 (라이트) |
  | `brand-cherry-tint` | #F7E1E4 / 다크 #4A1C24 | 로그인 안내 아이콘 원 |

- **쓰는 곳**: 앱 아이콘, 스플래시, 로그인 화면에만 쓴다. 로그인 뒤 앱 안은 아래의 조용한 기본 색과 상태 색을 그대로 쓴다.
- **에셋 만들기**: 마크 SVG를 고친 뒤 `pnpm render:brand` → `apps/mobile/assets/images/`의 아이콘·스플래시 PNG가 다시 만들어진다. 앱 안 로고(`CherryMark` 컴포넌트)도 같은 도형으로 맞춘다.

## 원칙

1. **숫자가 주인공**
   - 금액은 고정폭 숫자(tabular numbers)로 표시하고 오른쪽 정렬한다.
   - 단위는 항상 `원`을 쓰고, 천 단위 쉼표를 넣는다.
2. **색은 의미를 가진다**
   - 카테고리 색과 상태 색을 분리한다.
   - 카테고리 색은 아이콘 원, 카테고리 이름, 비율 막대에만 쓴다.
   - 상태 색은 배지에만 쓴다.
3. **목록은 줄 단위**
   - 카드를 쌓지 않고 얇은 구분선이 있는 줄로 보여준다. 한 화면에 많은 건이 보여야 한다.
4. **원문까지 한 번에**
   - 어떤 건이든 상세에서 원본 알림을 바로 볼 수 있다.
   - 원문은 고정폭 글꼴로, 옅은 배경 위에 그대로 보여준다.
5. **다크 모드 기본 지원**
   - 모든 색은 토큰으로만 쓴다. 각 토큰은 라이트·다크 값을 함께 가진다.
6. **군더더기 없는 말투**
   - 짧고 동사로 시작한다. 예: "지금 정리하기", "나누기".
   - 느낌표와 "성공적으로" 같은 표현은 쓰지 않는다.

- `bar`: 비율 막대, 차트

## 아이콘

- 선형(outline) 아이콘 한 세트만 쓴다. 기준 세트는 Tabler Icons이며, RN에서는 `@tabler/icons-react-native`를 쓴다.
- 크기: 목록 아이콘 원 32, 아이콘 18 / 탭 바 22 / 인라인 16
- 이체는 `arrows-exchange`, 입금은 `arrow-down-left`, 모임은 `users`, 원본 알림은 `bell`을 쓴다.

## 움직임

- 밀어서 처리할 때 넘어가는 지점: 줄 너비의 35%. 넘어가면 진동 피드백을 주고 해당 상태 색 배경이 드러난다.
- 시트 열고 닫기: 250ms, ease-out
- 처리된 줄이 사라질 때: 높이가 접히며 200ms
- 움직임 줄이기 설정을 켠 사용자에게는 애니메이션 없이 바로 전환한다.
