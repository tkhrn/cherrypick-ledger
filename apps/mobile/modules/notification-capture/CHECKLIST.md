# 실기기 확인 체크리스트

개발 빌드(`npx expo run:android` 또는 `eas build --profile development`)를 설치한 뒤 확인한다.

- [ ] 첫 설정에서 "권한 설정 열기" → 알림 접근에서 cherrypick을 켜고 돌아오면 다음 단계로 넘어간다
- [ ] 문자 권한을 허용하면 카드 승인 문자가 수집된다 (설정 → 수집 상태의 마지막 수집 시각이 바뀐다)
- [ ] 분석할 앱 목록에 설치된 금융앱이 "금융앱으로 보여요" 묶음 위쪽에 보인다
- [ ] 선택하지 않은 앱(예: 메신저)의 알림은 수집되지 않는다
- [ ] 비행기 모드에서 결제 알림을 받으면 "업로드 대기 N건"이 늘고, 네트워크가 돌아오면 0이 된다
- [ ] 앱을 최근 앱 목록에서 지운 상태에서도 알림이 수집·업로드된다
- [ ] 같은 결제에 대해 카드앱·문자·토스 알림이 오면 "지금 정리하기" 후 한 건으로 묶인다
- [ ] 배터리 최적화 예외를 켜지 않은 상태로 하루 두었을 때 수집이 멈추는지 확인한다 (멈추면 배너가 떠야 한다)
- [ ] 설정에서 기기 키를 폐기하면(DB에서 revoked_at 설정) 업로드가 멈추고 앱에 재등록 안내가 뜬다
